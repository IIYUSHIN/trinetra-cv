# ERR-CL-023 — remaining TIIR profile choices (PROPOSED)

Principal-builder reply authorizes implementing the remaining pure bindings and
choosing unspecified token/text spellings provisionally. No formal ratification.

Tensor MVP: dtype FLOAT32, layout NCHW, canonical byte_order LITTLE_ENDIAN,
schema_version=1, shape (1,3,H,W), positive I-JSON-safe integer dimensions.
Source tokens SUPERVISOR_CONSTRUCTED and RUNNER_REPORTED. Semantic tensor identity
uses JCS metadata with tensor_bytes_sha256 in existing DigestSha256 text form;
source and tensor_identity_digest are excluded from that preimage. Receipt digest
values remain raw bstr32. No float rounding, dtype conversion or silent reshape.
Canonical byte materialization accepts exact bytes or read-only C-contiguous
float32 memoryviews of the declared shape on little-endian hosts; unsupported
storage/shape/layout/byte order fails, never silently normalizes or casts.

Adapter identity/version and runtime provider/device text are preserved exactly,
1..1024 UTF-8 bytes, no narrow token grammar or Unicode normalization. Invalid
UTF-8 surrogate text fails; punctuation, spaces and non-ASCII identities are legal.
These are representation abuse bounds, not calibrated scientific thresholds.

Nested CBOR map keys (small integer keys, fixed per v1, in field order):
- original_input: 1 asset_id, 2 content_digest, 3 byte_size.
- tensor: 1 schema_version, 2 dtype, 3 shape, 4 layout, 5 byte_order,
  6 tensor_bytes_sha256, 7 tensor_identity_digest, 8 source.
- effective_input: 1 observability_level, 2 tensor_digest/null.
- model: 1 model_asset_id, 2 model_content_digest, 3 model_io_contract_digest,
  4 adapter_id, 5 adapter_version, 6 execution_assurance_class.
- runtime: 1 runner_image_digest, 2 resource_profile_digest,
  3 runtime_provider, 4 requested_device.
- output: 1 raw_output_asset_id, 2 raw_adapter_output_digest,
  3 semantic_output_asset_id, 4 semantic_output_digest,
  5 semantic_output_schema, 6 detection_count.
Top-level keys 1..17 follow the existing source; no changes to those assignments.
ReceiptId/StreamId use bstr16 per ERR-CL-019. Existing AssetId uses its existing
canonical domain text form, not a newly invented UUID conversion. All digest fields
use bstr32. Fields are required, nested maps closed, optional values explicit null.

Effective-input levels: EXACT_SUPERVISOR_TENSOR requires SUPERVISOR_CONSTRUCTED;
RUNTIME_REPORTED requires RUNNER_REPORTED; ORIGINAL_BYTES_ONLY, CONTRACT_ONLY,
UNAVAILABLE require null. These are observation metadata, not verification verdicts.
No effective-input digest or freshness evidence is fabricated when absent.

The model, runtime and raw-output bindings take already-computed upstream values.
They do not create model contracts, claim a container tag is an image digest, or
hash arbitrary JSON as a replacement RawAdapterOutputRecord. Producer conformance
remains NOT_RUN. Formal approval/reversal requires REV and consumer byte-vector,
parser, tensor, signing, output and continuity retests.
