# L-A-1-001 — IMP-0285 identifier contract resolution

Status: OPEN. Proposed record ERR-CL-016 (number subject to integration-owner assignment).

IMP-0285 requires ReceiptId and StreamId, reusing the existing primitive rules.
Source S000031 specifies opaque random 16-byte identifiers and CBOR byte strings.
Source S000067 specifies UUIDv4 for the stream and exact 16-byte UUID fields.
The frozen packet does not resolve these different accepted value sets.
Existing domain OpaqueId instead serializes a typed prefix plus 32 hex digits.

Request to Claude/integration owner: authorize the ReceiptId and StreamId domain
representations, their exact CBOR representation, and whether UUID version/variant
bits are mandatory. State the superseded source requirement explicitly.
No production identifier representation has been selected locally.

Impacted packets: IMP-0285, IMP-0303, IMP-0304, IMP-0305 and subsequent stream,
persistence and verifier consumers. Retest identifier rejection, round-trip,
wrong-kind confusion, canonical bytes and payload known-answer cases after REV.
The ordered lease stops at IMP-0285 pending this answer; IMP-0298 remains separately
blocked on the authoritative DetectionSet contracts.
