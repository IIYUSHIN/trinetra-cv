# L-A-1-003 — ERR-CL-021 PROPOSED: semantic digest substrate and content

Principal-builder hinge commit inspected:
a0efce858971426da8a7e14242a3fdd652b60d16. DetectionSet types are now available,
with PROPOSED ERR-CL-020 constraints. No independent acceptance is asserted.

The hinge note asks IMP-0298 to hash a new deterministic CBOR representation with
forced float64 values. Source S000031's DetectionSetContentDigest explicitly uses
SHA256(JCS(canonical semantic content)). The restriction against JCS substitution
for TIIR wire identity governs the signed CBOR/COSE receipt, not automatically the
preimage of every semantic digest bound inside that receipt. The current TIIR v1
payload codec forbids floats; it carries binary digest values, not detection arrays.

Request principal-builder REV: confirm whether semantic output identity remains
JCS or changes to a separately versioned CBOR semantic-content profile. If CBOR is
chosen, specify the exact content fields, keys, numeric encoding and byte vectors;
fixed float64 is a separate profile choice from RFC 8949 shortest encoding.
Do not weaken the receipt codec's no-float rule to encode semantic content.

Also settle content scope: source semantic content includes input and model
identity, coordinate space, class identities and canonical detections; the hinge
DetectionSet contains image digest/dimensions and class indices/detections but no
model or ontology identity. Do not infer those missing bindings from an object name
or omit them silently. Specify required additional inputs or approved exclusions.

This record follows the note's instruction to use the next number after 020.
Status PROPOSED, not a new ratified format. Exact source passages and detailed
comparison are retained privately, not committed as source-pack excerpts.

Impact: IMP-0298, IMP-0303/0304 output bindings, IMP-0325/0326, receipt tamper
fixtures and scientific generators consuming semantic digest identities. Required
retests: fixed-byte vectors, meaningful field changes, order/duplicate handling,
image/model/class/coordinate bindings, float exactness and consumer interoperability.

Resolution update: principal builder rechecked and withdrew the CBOR semantic
preimage instruction. Imported semantic_output from exact commit
a2f616de64199370ccf71f8c7dfa11607ff4dd3b implements versioned JCS/SHA-256 under
ERR-CL-021 PROPOSED. Reuse semantic_output_digest(...).raw; no new float codec.
The owner content-scope question remains recorded in 021, not silently resolved
as an ontology-coverage claim. This request no longer blocks implementation.
